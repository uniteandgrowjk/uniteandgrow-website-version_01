## Woher

1. https://gwfh.mranftl.com/fonts/outfit öffnen (google-webfonts-helper)
2. Zeichensatz "latin" wählen
3. Schnitte 300, 400, 500, 600, 700, 800, 900 anhaken
4. "Download files" → ZIP entpacken
5. Dateien umbenennen nach dem Schema oben (z. B. `outfit-v11-latin-300.woff2` → `outfit-300.woff2`)
6. Hier in `site/fonts/` ablegen

Alternative Quelle: https://fonts.google.com/specimen/Outfit → "Get font" → TTF,
danach mit https://cloudconvert.com/ttf-to-woff2 in woff2 wandeln.
